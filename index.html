Operational Efficiency

Productivity and CSAT combine into one score (75% Productivity, 25% CSAT), which is graded A–D. Operational Efficiency is then the worse of that grade and the Audit grade — so a weak audit result is never masked by strong productivity or customer scores.

Prod+CSAT Score = (Productivity points × 0.75) + (CSAT points × 0.25) → graded A–D
Operational Efficiency = WORSE OF ( Audit grade , Prod+CSAT grade )

Matrix Placement

The 4×4 matrix on the Dashboard tab plots Profitability (rows) against Transaction Volume (columns). Each of the 16 boxes has a name (e.g. Champion, Volume Trap, Critical Priority) and a recommended set of actions. Operational Efficiency is shown as a colored dot on each branch chip inside its box, rather than as a third matrix axis — so you can see profitability and volume placement at a glance, with operational health as an overlay.

Branch Health Index (BHI)

Every branch also receives a single weighted score (0–100), the BHI, used to rank all branches from strongest to weakest. Grade points: A = 10, B = 7, C = 3, D = 0.

CriterionWeight
Profitability25%
Transactions25%
Audit25%
Productivity15%
CSAT10%
BHI = (Profitability points × 2.5) + (Transactions points × 2.5) + (Audit points × 2.5) + (Productivity points × 1.5) + (CSAT points × 1.0)

This is calculated directly from the five underlying grades and does not route through the Operational Efficiency grade — Audit, Productivity and CSAT each contribute independently, weighted by their individual importance.

Ranking Methodology

Branches are ranked by highest BHI. Where two or more branches share the same BHI, ties are broken sequentially using the raw (pre-grade) value, in this order:

  1. Highest Profitability value
  2. Highest Transaction value
  3. Highest Audit score
  4. Highest Productivity value
